# 福彩3D 项目 · 长期记忆（项目约定与目的）

## 项目目的（精炼定义，2026-09-13 用户澄清）
本项目的**两层目的**：
1. （宪章第一条·原意）在严格治理下做统计学习 / 科学复现：用福彩3D 开奖数据检验"开奖是否可预测"，输出诚实结论，**不产出投注建议、不宣称稳定盈利**。
2. （**用户 2026-09-13 明确补充，为核心目的**）项目自带一层「**自动进化 + 决策辅助系统**」引擎，用以驱动项目进行**极致的探索与研究**。用户原话：没有这些引擎推动，所有项目研究和开发都将进展缓慢。
   - 即：自进化/决策辅助引擎不是"附加功能"，而是项目的**第一驱动力**。它负责持续生成假设、自动审计、量化"可预测性方向"、用激励账本奖惩正反双方，从而让研究自发向前滚动。
   - 已落地的引擎：`workbench/evolution_arena.py`（自进化元循环 + 决策方向科学评价）+ `workbench/incentive_ledger.py`（激励账本）+ `dashboard.py`「进化擂台」标签页。
   - **跨运行累积已落地（2026-09-13 续）**：`evolution_arena` 现在**有状态**运行——账本(`IncentiveLedger.from_dict`)、近失特征种子、运行计数持久化到 `reports/evolution-engine-state.json`，每次运行加载并累积；每次运行推进随机种子(`eff_seed=seed+prev_runs*7919`)以探索新领地，同时把上一运行的近失特征种子作为 `cross_seeds` 回流重放，实现"自进化在运行间真正累积学习"。防双计：基桩 15 项主张 id 固定、跨运行不重复提交/计分；生成物(mut/synth/xseed) id 嵌入 `run` 序号保证全局唯一，避免不同运行生成的特征不同主张撞同一 id 污染账本。`--reset-state` 清空累积、`--no-persist` 单次不写回。验证：连续 3 次运行 runs=1→2→3，账本 15→47→63 条目全唯一、基桩永不膨胀。

## 研究姿态约定（用户 2026-09-14 明确，为核心 operating principle）
- **严禁"躺平式结论"**：不得以"无法预测 / 与随机不可区分"为由终止探索。对天气、湍流、生命起源等已知混沌系统，科学家的态度是"明知难预测仍持续建模、逼近、追踪弱信号"，而非宣告"不预报了"。本项目同理——这种"预埋不可能心理"被用户明确点名为有害、阻碍新文明与发现。
- **"无法预测"是待检验的开放假设，不是终局**：所有"未检出可预测信号"必须框定为"当前样本与特征空间下的证据不足"，并显式声明探索持续开放、不预设不可预测。
- **主动寻找微妙联结与蝴蝶效应**：随机问题生成器应优先合成"事物之间的关系/交互"假设（位间耦合、和值—位值关联、跨度—单值关联等），而非仅单变量谓词。关系型原语：pos_pair / sum_digit / span_parity（已落地于 evolution_arena.FEAT_POOL）。
- **近失=开放假设而非失败**：p<0.2 但未过 FDR 的主张作为 `open_hypotheses` 持续追踪，并以近失种子回流下一轮 `cross_seeds` 换角度重验。
- **引擎不设"找到即停"**：已移除"连续 N 代无信号则 break"的收敛终止；仅保留 `max_gens` 硬上限（计算边界），跨运行推进随机种子+回流近失继续探索。
- 与上述**不冲突**：宪章的诚实闸门（FDR / 安慰剂 / 复现 / OOS 盲窗 / 与均匀随机基线对照 / 不夸大可预测性 / 不产投注建议）全部保留；改变的只是"结论措辞与探索循环的终止逻辑"，不是统计方法论。

## 人机协作稳定性约定（用户 2026-09-14 提出：人是系统中最大的不稳定因素）
- **核心判断**：任何系统里，人几乎都是最大不稳定源，且对系统影响权重很大（认知偏差、情绪化停启、阈值随意改、确认偏误 cherry-pick、权威定论、缺席导致探索停摆）。本项目的"自动进化+决策辅助"第一驱动力，正是用来**把探索的连续性与结论的诚实性从人的临时状态里解耦**。
- **设计原则与落地状态**：
  1. **护栏代码化，而非意愿化**：把宪章与研究姿态约定写成机器强制不变量，使人（含用户本人状态不佳时）无法悄悄关闭（如滥用 `--reset-state`、临时改裁决措辞须留痕）。【部分落地】
  2. **人的干预 = append-only 审计 + 自保护通道**：任何人工调参/加因子/推翻裁决/重置，只能以受控、分级、带自保护的"干预请求"提交，绝不静默覆盖；全部 append-only 记录。【✅ 已落地 2026-09-15，见 `workbench/interventions.py`】
  3. **独立"偏差审计"代理**：扫描人工干预是否带偏置（阈值突变、反复无理由 reset、cherry-pick 近失）。【待落地】
  4. **让探索自治、人退居监督**：用定时自动化让引擎持续滚动（已建「福彩3D 进化引擎·每日跨运行累积」自动化，每日 23:00 累积运行，不重置；2026-09-15 已把干预治理层写入其 prompt）。【✅ 落地】
  5. **多样性+选择压平抑个体噪声**：并行多假设、多特征族、用 FDR/证据做选择压，而非依赖单一人类判断；人的意见只是众多选择压之一且是噪声最大的那个。【✅ 架构内已体现】
  6. **漂移检测**：追踪人工干预的时间序列一致性（阈值方差、reset 频率），超界则暂停人工覆盖待复核；当前由 `interventions.count_recent_resets` 实现"重置滥用"稳态检查。【部分落地】
- **干预治理层「自主神经稳态」已落地（2026-09-15）**：
  - 文件：`workbench/interventions.py`（实现 ②④⑥）。CLI：`python interventions.py {param_change|add_factor|override_verdict|reset} --by … --set … --spec … --why …`。
  - 风险分级：param_change→L1 或 L2（若涉 alpha/fdr_q/prize/cost/oos_n）；add_factor/override_verdict→L2；reset→L1。
  - 稳态检查 5 项：泄漏检测 / 显著性膨胀 / 重置滥用 / 无证据推翻 / cherry-pick。决定：accept(应用并持久化) / quarantine(记录待复核) / reject(记录并拒绝)。high 风险且为 override_verdict/reset → 直接 reject；其它 high → quarantine。
  - 落盘：`reports/interventions.jsonl`(append-only 账本) + `reports/engine-overrides.json`(已校验参数覆盖) + `reports/engine-factor-registry.json`(声明式因子注册表)；声明式因子 DSL 仅接受 `pos_parity_eq/sum_mod_eq/digit_at/span_mod_eq/pos_diff_eq`，纯单 draw、位置 0..2，杜绝代码注入。
  - **已接入引擎**：`evolution_arena.EvolutionArena` 在每代开局先 `load_overrides()` 覆盖参数（窗口计算前），并 `_load_user_factors()` 把注册因子作为基桩候选参与评估/审计/账本；运行报告 `config.overrides_applied` / `config.user_factors_loaded` 可见。已端到端验证。
  - **已接入大屏**：`dashboard.py` 新增「干预治理」标签页，展示累计干预数、accept/quarantine/reject 分布、生效参数覆盖、注册因子、append-only 账本；`engine.collect_state()` 注入 `interventions` 状态。
- 与宪章不冲突：上述均属"把人类不稳定因素工程化隔离"，不改动统计方法论与诚实闸门。

## 遇到困难时的应对原则（用户 2026-09-14：「头脑风暴解决方案并补齐，万一有效果呢」）
- **这是对"开放探索姿态"的操作化补强**：当回测/搜索给出"未检出信号"时，**不得停步于报告无信号**——必须主动头脑风暴新的假设空间并补齐探针，"万一有效果呢"。
- 已落地的"补齐"实践：
  - `debate_arena.run_arsenal`（反方武器库）已对**单位置**做完备随机性检验（拟合优度/游程/滞后自相关/信息熵/Ljung-Box/最大连号/CUSUM），共 24 项。
  - `workbench/structure_tests.py`（2026-09-14 新增）：补齐**跨位置-跨时滞耦合**与**高阶马尔可夫**盲区——用互信息(MI)+Pearson+高阶 MI 增量，全部置换检验 p 值 + Benjamini-Hochberg FDR。结果：30 项检验中 2 项原始 p<0.05（百位(t)↔个位(t-1) MI p=0.047、十位(t)↔百位(t-1) MI p=0.012），但**经 FDR 后无一存活**→ 该方向被诚实收窄，弱联结作为 open_hypotheses 持续追踪。
  - `workbench/external_coupling.py`（2026-09-14 新增）：补齐**外部/跨域耦合（日历域）**盲区——从每期开奖日期派生 星期/周末/月份/月初/月末，卡方独立性(15 项) + 均值置换检验(9 项) 共 24 项，全部 BH-FDR。结果：2 项原始 p<0.05，**FDR 后无一存活**→ 该方向被诚实收窄（但仍可继续追踪节假日/农历/销量等其它外部域）。
  - `workbench/near_miss_ensemble.py`（2026-09-14 新增）：补齐**近失假设集成/元学习**盲区——收割近失候选（基桩族经 `_build_pro_claims` 映射 + 合成 feats 重建 + 训练窗内确定性 mini 生成补足），投票/堆叠集成(min_votes 扫描)，严格时间前向 OOS 盲窗评估，对照均匀随机基线(二项/Wilson CI) + BH-FDR + Fisher/Stouffer 组合 p。结果：池大小 8，训练窗命中率 3.0%(p=0.016 显著，属选择偏差) → OOS 命中率 1.67%(p=0.453 不显著) → FDR 无存活、Fisher p=0.965、Stouffer Z=-0.367；诚实收窄。该模块清晰演示了"训练窗选择偏差 vs OOS 盲窗"的落差，正是其设计价值。
  - 两新模块均已接入大屏：`dashboard.py` 新增「外部耦合」「近失集成」标签页，`engine.collect_state()` 注入 `external_coupling`/`near_miss_ensemble`；`registry.py` 注册 `external_coupling`/`near_miss_ensemble` 为可运行功能（L1/探测）。
- 后续"万一有效"的头脑风暴方向（待择机补齐）：① 外部/跨域耦合（福彩3D vs 体彩排列3 同期、日历/节假日/农历、机型/球组轮换——【日历域已落地 2026-09-14，继续拓宽域】）；② 更高阶非线性（order-3 马尔可夫、符号动力学/置换熵、压缩复杂度）；③ 近失假设的集成/元学习（多弱假设投票/堆叠，严格 OOS）——【已落地 2026-09-14】；④ 决策/风险层而非预测层（Kelly 仓位在~0 edge 下的下行有界）；⑤ 对抗性基线审计（"均匀随机"是否为正确零假设，实测联合分布是否存在机械/规则性约束）；⑥ 贝叶斯稀疏效应搜索（对微小效应更灵敏）；⑦ 主动/自适应实验设计（针对性放大复测近失联结）。
- 与宪章、开放探索姿态不冲突：补齐的是**假设空间与探针**，统计闸门(FDR/置换/OOS/随机基线对照)保持不变；任何存活联结须经 OOS 盲窗+独立样本复现，不得包装成盈利策略。

## 关键约束（贯穿所有代码，源于宪章）
- 时间序列只能按期号向前训练；未来开奖绝不泄漏到过去特征/模型选择。
- 预测必须先冻结、后读实开评估。
- 所有复杂方法必须与**均匀随机 + 简单频率基线**比较。
- 结论须诚实：方向得分落入零分布带时一律"未检出可预测信号"，绝不包装成盈利策略。
- 数据主权：权威库 `sd3d_history.sqlite3` 只读查询，已提交数据不可删改；错误须追加 before/after 修正记录。
