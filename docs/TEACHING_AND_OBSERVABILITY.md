# 教学与可观测性设计

## 教学单元

1. 从网页 iframe 识别真实数据源，保存原始响应和哈希。
2. 用数据契约发现编码、重复和期号错误。
3. 用描述统计区分“看起来有规律”和可重复证据。
4. 用时间滚动回测理解数据泄漏。
5. 用均匀随机基线和 Monte Carlo 解释命中波动。
6. 用校准、Brier 和对数损失理解概率预测。
7. 用置换检验和多重比较解释“刁钻规律”的假阳性。
8. 冻结预测后获取新一期结果，完成盲评和事后更新。

每个单元都应有输入、命令、预期产物、失败案例和一个可复现实验，而不是只给结论。

## 运行观测

每次运行记录：`run_id`、开始/结束时间、脚本版本、数据源 URL、HTTP 状态、响应哈希、行数、期号范围、清理计数、模型、参数、随机种子、耗时、警告和产物路径。

质量门禁至少包括：源页面可达、数据行数大于零、期号无重复、数字域合法、日期可解析、快照哈希变化可解释、预测生成时没有读取验证集结果。

## 持续更新流程

```text
抓取新快照 -> 校验 -> 与上一快照比较 -> 冻结历史预测
        -> 写入实际结果 -> 生成盲评 -> 更新指标
        -> 记录失败案例 -> 仅在训练边界之后重训
```

模型只能因预登记规则升级；不能因为某一次没命中就临时改规则。每次升级保留旧模型作为 challenger，报告升级前后差异。

## 最终报告声明

报告首页必须显示：这是随机彩票的统计学习实验，不构成投资或投注建议；模型排名不等于真实概率优势；“排除”不是确定排除；任何短期命中都可能来自随机波动。
