# 综合证据大脑设计

## 定义

“数字生命”在本项目中是一个比喻。工程上实现的是有记忆、有状态、有反馈、有审计和有边界的证据决策中枢，而不是拥有意识或可以自行突破治理规则的程序。

## 五层结构

```text
感知层：网页、SQLite、JSONL、原始快照、实际开奖
记忆层：运行清单、模型版本、冻结预测、prediction_outcomes、失败记录
推理层：统计诊断、概率评分、回测、Bootstrap、漂移分析
决策层：模型排序、综合证据、风险等级、教学结论
进化层：提出模型/规则改进案，经过专家审计后才可实施
```

## 进化闭环

```text
新数据
 -> 质量门禁
 -> 盲评旧预测
 -> 更新模型指标
 -> 检测漂移和偏差
 -> 生成进化提案
 -> subagent 专家审计与投票
 -> 新版本 challenger
 -> 时间回测
 -> 决定是否进入实验主线
```

## 绝对边界

- 大脑不能自动修改宪章、删除数据或覆盖历史报告。
- 大脑不能用新开奖结果修改旧预测。
- 大脑不能因为一次命中就提高模型等级。
- 大脑不能把模型排名说成真实概率优势。
- “进化”必须留下 proposal、证据、投票、版本和回滚路径。

## 当前实现

`evidence_brain.py` 是第一版综合汇总器。它读取已有报告和盲评归档，生成 `brain-decision-latest.json`。它可以选择“实验性当前模型”，但不会自动把模型升级为正式模型，也不会自动修改代码。
